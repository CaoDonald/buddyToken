口径：每积分 Token = 该模型 Token 合计 ÷ 积分合计，即「花 1 积分能换到多少 Token」。 含免费额度（0 积分）在内的模型会单独标注，不参与比率排序。
解读提醒：这个数字低不代表模型差——复杂任务才会用强模型，它天然 Token 多、积分高。 要横向比性价比，请结合「单次积分」和「缓存率」一起看。
响应 P50 / 首字延迟 / 输出速度：三者都针对单次 API 请求， 已排除工具执行时间但含网络与排队。后两者由「耗时 ≈ 首字延迟 + 输出 token ÷ 速度」 分箱回归拟合得出（样本不足 60 条时留空）。带 * 表示样本不足 30 条。 单次请求耗时不等于用户等待时间——用户等的是整个回合，见上方 KPI 的「模型耗时占比」。
